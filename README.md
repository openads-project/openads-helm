**Essential OpenADS Helm Charts**

This repository contains essential Helm charts for [***OpenADS***](https://openads-project.github.io/), the *Open Automated Driving Systems* project. Essential charts are those that do not directly belong to a specific OpenADService. In particular, the [openadservice](./charts/openadservice) chart provides a base structure and configuration for all dependent charts of specific OpenADServices, which are maintained in their respective repositories.

## 🚀 Usage

> [!NOTE]  
> Tested with k3s v1.35.7, Helm v3.19.0, and Helmfile v1.1.7.

Helm charts are stored as OCI artifacts in the GitHub Container Registry and can be installed directly from there.

```bash
helm show all oci://ghcr.io/openads-project/openads-helm/openadservice
helm template oci://ghcr.io/openads-project/openads-helm/openadservice
helm install openadservice oci://ghcr.io/openads-project/openads-helm/openadservice
helm uninstall openadservice
```

For OpenADServices, dedicated Helm charts are automatically generated by the [openads-dev-environment](https://github.com/openads-project/openads-dev-environment#helm-chart-generator), e.g., in [openads_demo_service](https://github.com/openads-project/openads_demo_service/blob/main/deployment/helm/Chart.yaml).

## 🛠️ Utilities

### Generate Helmfile from Docker Compose

The [OpenADStack](https://github.com/openads-project/openadstack) and its integration into the [OpenADSim](https://github.com/openads-project/openadsim) simulation platform are maintained and deployed using Docker Compose. Equivalently, using the automatically generated Helm charts for all OpenADServices, the same stack can be deployed on Kubernetes.

[`generate_helmfile_from_compose`](./utils/generate_helmfile_from_compose) converts a Docker Compose project into an equivalent [Helmfile](https://helmfile.readthedocs.io/en/latest/) setup including per-service values. For CI integration, a reusable GitHub workflow is provided.
